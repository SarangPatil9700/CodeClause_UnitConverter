# 🌍 Length Converter  

Length Converter is a web-based tool that allows users to seamlessly convert between different units of length. Whether you need to convert feet to meters, inches to centimeters, or miles to kilometers, this application provides real-time and accurate conversions in a user-friendly interface.  

🔗 Live Demo: [Length Converter](https://sarangpatil9700.github.io/CodeClause_UnitConverter/)  

## 🚀 Features  

### 📏 Real-Time Conversion
- Users can input a value in any field, and the corresponding values in other units will update instantly.  
- Eliminates the need for manual calculations, making conversions quick and accurate.  

### 🔄 Multiple Unit Conversions
This converter supports seven different length units:  
- Feet (ft)  
- Meters (m)
- Inches (in)
- **Centimeters (cm)**  
- **Yards (yd)**  
- **Kilometers (km)**  
- **Miles (mi)**  

### 🎯 **User-Friendly Interface**  
- A simple and clean design enhances usability.  
- Each unit has a separate input box for easy data entry.  
- Minimalistic and distraction-free layout to focus on conversions.  

### ⚡ **Instant Input Handling**  
- The app listens for user input and dynamically updates all related fields.  
- No need for a "Convert" button—changes reflect automatically.  

### 🎨 **Responsive & Lightweight**  
- The design is **responsive**, making it usable on desktops, tablets, and mobile devices.  
- Optimized with **vanilla JavaScript** (no external libraries required), ensuring a **lightweight** and fast experience.  

## 🛠️ Technologies Used  
The project is built using the following web technologies:  
- **HTML** - Structure and layout of the web page.  
- **CSS** - Styling and responsive design.  
- **JavaScript** - Core logic for unit conversion.
